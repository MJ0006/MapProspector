1. First run

  1. Install: run MapProspector-Setup-x.y.z.exe (from GitHub → Actions → Windows app → Artifacts, or a Release). Windows SmartScreen warns because the app isn't code-signed: More info → Run anyway.
  2. Open it from the Start menu or desktop shortcut. It starts its own server and shows the Dashboard.
  3. Your data (database, client vaults, uploads, .env) lives in %APPDATA%\MapProspector. Updating or uninstalling the app keeps it. File → Open data folder takes you there; back it up by copying it.
  4. Closing the window keeps MapProspector in the system tray, so schedules, automations and review syncs keep running. Right-click the tray icon to quit, or turn on Start when I sign in to Windows.
  5. Light / dark: the ◐ Theme button at the bottom of the menu.
  6. From VS Code instead: see the README (uvicorn app.main:app, then open http://127.0.0.1:8000).

4. Finding clients

  1. Find leads: type a niche (e.g. roofer) and an area → Search. Each result shows opportunity flags (no website, few reviews, low rating) so you see who needs help. Filters: no website only, max rating, max reviews. Without a Google key it shows clearly labelled demo businesses.
  2. Save lead adds the business to Contacts. Save + heat map saves it and opens a new scan for it.
  3. New rank scan: keywords (one per line), provider (Places, DataForSEO or demo), surface, grid size, spacing and shape. Preview on map shows the points and how many searches it costs → Run scan. Add a schedule to repeat it.
  4. Heat map: each pin is where that business ranks when someone searches from that spot. Click a competitor in Flip the map to see their map instead: that's your sales story (“they own the north side, you don't”).
  5. Share link gives a page without the app's menus to send to the prospect; Print / PDF makes a PDF.
  6. On the contact: Run website audit (listing and website checks, each showing what it observed) and AI visibility (how AI assistants answer about the business). Draft outreach email (AI) on the audit writes a first email for your approval.

5. CRM and outreach

  1. Contacts: everyone you saved, imported (CSV: business_name, first_name, email, phone, website, address, tags) or who filled a form. Search and filter by status and source.
  2. Contact page: timeline, notes and calls (Log), tasks, deals, scans, audits, messages. Add to outbox writes a message; Start runs an automation for this contact; Convert to client when they sign.
  3. Pipeline: drag deals between stages; won and lost are tracked. Tasks: follow-ups with a 14-day calendar.
  4. Outbox: nothing reaches a cold contact until you approve it here. Edit, Approve, Cancel, or Copy text / Mark sent for SMS or email you send yourself. Without SMTP, approved emails wait here.
  5. Automations: a trigger (new form submission, new contact, new deal, deal moved to a stage, contact field updated, or started manually), optional filters, then steps: send email or SMS, wait, create task, update field, add tag, move deal, continue only if…, stop if the review link was clicked, send questionnaire, send review request. Runs show on the contact; Stop ends one.
  6. Forms & spam: a hosted lead form for a client's site, with spam rules (a hidden honeypot field, plus blocked keywords, emails, domains, IPs, countries, links in the message and bad phone formats); Not spam rescues a false alarm. Questionnaires: onboarding questions; use the per-client link so answers go into that client's vault.

6. Running a client's local SEO

  1. Convert to client (on the contact) creates the client and its Local SEO Brain vault.
  2. Overview → Add evidence: upload what you have (Business Profile export, reviews, citations, Search Console, a research pack) → Upload to vault. Then Update plan writes the Health Scorecard and Action Roadmap. They stay marked Draft and every line cites its evidence; missing evidence is marked, not guessed.
  3. Posts: pick a topic → Draft (AI) → edit → Approve, then Publish now, Schedule, or Mark posted if you post it yourself.
  4. Reviews: Sync from Google, Draft with AI or Draft replies for unanswered (AI), then Approve & post reply. Create request sends a customer the same Google review link everyone gets (no gating).
  5. Photos: upload; files get descriptive names, optional GPS stamp (metadata only, no ranking claim); Publish or Drip selected to spread them out.
  6. Profile lock: Lock the current listing; the app checks it every 6 hours and shows any change for you to Accept change or Revert via Google.
  7. Insights: Business Profile views, calls and directions plus Search Console (needs Google sign-in). Optimize: AI drafts for description, categories and services. Citations: the client's NAP profile, Run citation audit, Export CSV, Send to brain.

7. Reports

  1. Client → Reports: name, sections (rankings, reviews, posts, AI visibility, …), recipients, schedule → Create.
  2. Build now makes one. If it needs approval, check it and press Approve & send; otherwise it's emailed on schedule (with SMTP) as a link. Download HTML or Open / print for a PDF.
  3. Branding (name, colour, logo, reply-to, postal address) is under Settings → Branding.

8. Ask, Journal and lessons

  • Ask: plain-English questions about your data (“Which competitor owns the north side in my latest roofer scan?”). The AI reads your data through read-only tools and cites what it used.
  • Journal: every job, AI call (and which platform answered), failure, and what you did with each AI draft (used as-is, edited, rejected). Propose lessons turns your edits into short writing lessons; Approve the good ones and every future draft follows them.
  • Claude Code / VS Code: this repo's MCP server lets Claude Code query your data and start scans.

10. Rules the app follows

  • Nothing goes to a cold contact without your approval; every email has an opt-out line and your postal address; do-not-contact is respected.
  • Review requests send every customer to the same Google review link. There is no review gating.
  • No invented scores: every grade shows its formula, audits list exactly which checks ran, plans are marked Draft and cite evidence.
  • No ranking guarantees or keyword-stuffed names; GPS stamps are metadata only.
  • AI output is always a draft for you to approve.

11. Troubleshooting

ProblemWhat to do
Something failedThe notice bar links to the Journal failures. In the Windows app, File → Open server log shows the server's own log.
“usage limit reached”The next AI platform answers automatically. Add another platform on Settings, or Try again now after the reset time.
An AI platform says “not signed in”Settings → AI platforms → Sign in, finish in the terminal and browser, then Try again now.
A key doesn't seem to workCheck it has no spaces or quotes in .env, restart the server, and look at Settings.
Google sign-in failsThe redirect URI must be exactly http://127.0.0.1:8000/gbp/oauth/callback. If another program uses port 8000, the app uses a different port and Google sign-in won't match: close that program and restart.
Links don't open for clientsThey need a tunnel and PUBLIC_BASE_URL.
Schedules didn't runThey run only while the app runs. Keep it in the tray, or turn on Start when I sign in to Windows.
SmartScreen / antivirus warning on installThe installer isn't code-signed. More info → Run anyway.
